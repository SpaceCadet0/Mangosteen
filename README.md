# Mangosteen

Офлайн-конвертер файлов для macOS «в ноль кликов». Начните перетаскивать файл, коротко нажмите
клавишу-модификатор, и у курсора появится колесо. Бросьте файл на нужный сегмент, и результат
появится рядом с оригиналом.

| Клавиша во время перетаскивания | Колесо |
|---|---|
| `⇧ Shift` | Конвертация: изображения (PNG, JPG, WebP, HEIC, TIFF, AVIF, BMP, GIF, PDF; вход SVG, PSD, ICO…), PDF → картинки/текст/DOCX, документы DOCX/ODT/RTF/RTFD/TXT/Markdown/HTML ↔ друг в друга и в PDF, субтитры SRT/VTT, таблицы CSV/TSV, архивы ZIP/TAR/TAR.GZ (и папки → архив), видео MP4/MOV/MKV/WebM/AVI/WMV → друг в друга, GIF и MP3, аудио MP3/M4A/WAV/FLAC/OGG/Opus/AIFF/WMA |
| `⌘ Command` | Инструменты: видео и аудио — обрезка, разделение, скорость, сжатие, громкость (EBU R128), запикивание; аудио — каналы, визуализатор в MP4; видео — кадрирование, склейка, кадры в PNG, скрытие областей с собственным временем; сжатие (пресет, качество, целевой размер, ресайз, смена формата; PDF), обрезка (рамка, пропорции, точный размер), редактор фото (свет, цвет, детали, эффекты), пометки (стрелки, фигуры, текст, номера, карандаш, маркер, лупа, картинки), фон (цвет, градиент, изображение, исходное изображение с размытием; отступ, углы, тень), коллаж (сетка, ряд, колонка, главное фото), скрытие лиц и текста (Vision; заливка, размытие, пиксели), страницы PDF (порядок, поворот, дубли, удаление), метаданные (просмотр, правка, удаление геопозиции или всего), PDF из фото, объединение PDF, распаковка архивов (список будет расширяться) |
| `⌃ Control` | Действия: AirDrop, Float (плавающая полка для файлов), копировать, переместить, скопировать путь, открыть в терминале |

Клавиши настраиваются в «Настройках». Всё работает локально, без лимитов и без отправки файлов куда-либо.
Без перетаскивания то же самое доступно через меню в строке меню: выберите файлы и кликните по сегменту.

Подробный план развития: [docs/PLAN.md](docs/PLAN.md).

## Установка

Требования: macOS 14+, Xcode 26+, [XcodeGen](https://github.com/yonaskolb/XcodeGen) и утилиты из Homebrew,
которые будут встроены в приложение:

```bash
brew install xcodegen webp ffmpeg
```

Собрать автономное приложение (ffmpeg, ffprobe, cwebp и gif2webp с библиотеками внутри) и установить в /Applications:

```bash
scripts/release.sh --install
```

Без `--install` готовое приложение остаётся в `build.noindex/release/Build/Products/Release/Mangosteen.app`.
При первом запуске откроется окно «Как пользоваться»; позже оно доступно из меню значка.

## Разработка

```bash
xcodegen generate
xcodebuild -scheme Mangosteen -derivedDataPath build.noindex build
open build.noindex/Build/Products/Debug/Mangosteen.app
```

Тесты:

```bash
xcodebuild -scheme Mangosteen -derivedDataPath build.noindex test
```

Отладочная сборка умеет снимать окна инструментов для проверки вёрстки:
`Mangosteen --snapshot <id пункта колеса> <выход> <файлы…>` (см. `AppDelegate`).

Приложение не использует песочницу и подписывается ad-hoc. Оно предназначено для личного использования.
