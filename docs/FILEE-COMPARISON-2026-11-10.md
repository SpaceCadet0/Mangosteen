# Что взять у Filee — предложения для Mangosteen (2026-11-10)

Источники: репозиторий `KnifeLemon/Filee` (README, CHANGELOG 2.2–2.4, список релизов), сайт filee.sh (главная и
страница командной строки). Код Filee не читался, приложение не запускалось — описание их функций взято из их
собственных текстов.

## Коротко о конкуренте

- Filee 2.4.0 (2026-11-09), MIT, C# и Avalonia, Windows / Linux / macOS (macOS помечена как превью, без
  нотаризации). 24,7 тыс. звёзд на GitHub, 22 языка интерфейса.
- Тот же жест, что у нас: зажать клавишу, тащить файл, бросить на сектор круга у курсора.
- Упор на число форматов (заявлено 255–270): офисные документы без Office, HWP, электронные книги, CAD, 3D,
  шрифты, геоданные. Тяжёлые движки (FFmpeg, LibreOffice, calibre, Ghostscript, Pandoc) скачиваются по запросу.
- Размер: `.dmg` для Apple silicon — 138 МБ, и это без FFmpeg. У нас архив 21,7 МБ, приложение 51 МБ вместе с
  FFmpeg (36 МБ из них — утилиты).

**Где Mangosteen уже сильнее:** размер; FFmpeg внутри, видео и аудио работают сразу; три колеса; полка Float,
AirDrop и действия с файлами; инструменты для аудио (громкость, запикивание, каналы, визуализатор), таймлайн с
обрезкой и делением, скрытие областей на видео, коллаж; распознавание текста и удаление фона средствами macOS.

**Где сильнее Filee:** число форматов, настройка круга, пресеты и папка сохранения, работа из браузера, папки
наблюдения, командная строка, автообновление, языки, субтитры из речи и перевод локальным ИИ.

## Как читать оценки

- **Стоимость** — трудоёмкость в рабочих днях одного разработчика, с тестами, переводами на ru/en/es и снимками
  окон. Это прикидка по знанию кода Mangosteen, а не расчёт; ошибка в полтора-два раза возможна.
- **Размер** — прирост приложения на диске. Сейчас 51 МБ (архив 21,7 МБ). Архив растёт примерно на 40–45% от
  прироста приложения.
- Деньги нужны только там, где это указано отдельно (подписка Apple Developer для нотаризации).
- **[проверено]** — возможность проверена на этом Mac командой; **[по документации]** — не проверялась.

## Предложения по убыванию важности

### 1. Больше форматов без новых библиотек

Самое выгодное: то, что система и встроенный FFmpeg уже умеют, а колесо не предлагает.

| Что | Чем делается | Стоимость | Размер |
| --- | --- | --- | --- |
| Архивы: чтение 7Z, ISO, TAR.XZ, TAR.BZ2; запись 7Z и ISO | системный `tar` (libarchive 3.7.4) **[проверено]** | 1–2 дня | 0 |
| Архивы: чтение RAR, CAB, DMG | `tar` **[по документации]**, `hdiutil` для DMG | 1 день | 0 |
| Фото: чтение RAW (CR2, CR3, NEF, ARW, DNG, RW2…), JPEG XL, DDS, DICOM | ImageIO **[проверено]** | 1 день | 0 |
| Фото: запись ICO, ICNS, PSD, TGA, OpenEXR | ImageIO **[проверено]** | 1 день | 0 |
| Видео: HEVC и AV1 как цели, аппаратное кодирование | `hevc_videotoolbox`, `h264_videotoolbox`, `libsvtav1` в нашем FFmpeg **[проверено]** | 2–3 дня | 0 |
| Видео: чтение FLV, MPEG, TS, M2TS, 3GP, VOB; аудио: AMR, APE, AC3, DTS | FFmpeg **[по документации]** | 1 день | 0 |
| Субтитры: ASS/SSA, извлечение дорожки субтитров из видео | FFmpeg, кодировщики `srt` и `ass` **[проверено]** | 2 дня | 0 |
| Данные: JSON ↔ CSV/XLSX | Foundation | 2 дня | 0 |

Итого 11–13 дней, размер не меняется. Заодно закрывает пункт 1.6 отчёта проверки (обычный `.gz`).

Аппаратное кодирование — отдельная польза: конвертация видео станет в несколько раз быстрее и меньше грузит
процессор; цена — файл крупнее при том же качестве, поэтому нужен выбор «Быстро / Меньше размер».

### 2. Папка сохранения, имена и готовые наборы настроек

У Filee: пресеты с качеством, размером, папкой сохранения («рядом», выбранная папка, «спрашивать каждый раз»),
шаблоном имени, сохранением дат оригинала. У нас результат всегда пишется рядом, а качество задаётся одно на всё
приложение.

- Что сделать: в настройках — куда сохранять и что делать, если папка только для чтения (сейчас это ошибка);
  сохранять даты оригинала; для колеса конвертации — несколько своих наборов («JPG 80% до 1920 px»).
- Стоимость: 5–7 дней. Размер: 0.
- Правило «оригинал не меняется, результат рядом» остаётся значением по умолчанию.

### 3. Настройка колёс

У Filee: сектора переставляются перетаскиванием, свой круг на каждый тип файлов, вторая сторона круга (Tab или
колесо мыши) для редких форматов, группы секторов, отключение целых областей.

- Что сделать: в настройках скрывать и переставлять дольки по типам файлов; вторая сторона колеса для редких
  целей. Нужно и нам самим: у фото уже 10 долек, и пункт 1 добавит новые.
- Стоимость: 6–8 дней (настройки 3–4, вторая сторона 3–4). Размер: 0.
- Каждая долька по-прежнему со значком и подписью внутри; проверка снимками на ru/en/es.

### 4. Субтитры из речи

У Filee: SRT из видео через Whisper, всё локально.

| Вариант | Стоимость | Размер |
| --- | --- | --- |
| Распознавание речи macOS на устройстве (`Speech`) **[по документации]** | 5–7 дней | 0 |
| whisper.cpp с моделью внутри приложения | 6–8 дней | +80 МБ (модель base) или +470 МБ (small), плюс 2–5 МБ кода |
| whisper.cpp, модель скачивается по запросу | 8–10 дней | +2–5 МБ |

Рекомендация: начать с системного распознавания — приложение не растёт, а таймлайн и запись SRT у нас есть.
Качество и набор языков системного движка надо проверить на русском до начала работ. Третий вариант требует
сети, то есть отступления от правила «в сеть только по кнопке обновлений».

### 5. Папки наблюдения

У Filee: всё, что попадает в папку, конвертируется по выбранному пресету; оригиналы можно откладывать.

- Что сделать: список папок в настройках, для каждой — цель; ждать, пока файл перестанет расти; пропускать
  временные файлы; не ходить по символическим ссылкам.
- Стоимость: 5–7 дней. Размер: 0.
- Зависит от пункта 2 (куда класть результат и как называть).

### 6. Автообновление

У Filee: проверка новых версий в фоне и установка одной кнопкой, с проверкой подписи. У нас «Проверить
обновления» только открывает страницу релиза.

- Что сделать: подключить Sparkle (подпись обновлений EdDSA, собственный ключ).
- Стоимость: 3–4 дня, плюс 1–2 дня на подпись Developer ID и нотаризацию, если их делать.
- Размер: +3–4 МБ.
- Деньги: Apple Developer Program — 99 долларов в год, только если нужна нотаризация. Sparkle работает и без
  неё, но Gatekeeper продолжит предупреждать при первой установке.
- Фоновая проверка версий — это выход в сеть без нажатия; нужен переключатель и решение, включён ли он по
  умолчанию.

### 7. Перетаскивание из браузера

У Filee: картинку, ссылку на файл или загрузку можно тащить из браузера прямо на круг; ссылка скачивается.

- Что сделать: принимать перетаскиваемые из Safari и Chrome картинки (браузер отдаёт сам файл, сеть не нужна) и
  сохранять оригинал в «Загрузки». Скачивание по ссылке — отдельная необязательная часть.
- Стоимость: 3–4 дня для картинок, ещё 3–4 дня для ссылок (с запретом локальных адресов, как сделано у них
  в 2.4.0). Размер: 0.
- `DragMonitor` сейчас смотрит только на файлы в буфере перетаскивания; эта же правка — удобный момент убрать
  лишнюю нагрузку из пункта 1 раздела «Ресурсы» отчёта проверки.

### 8. Командная строка

У Filee: `filee convert *.heic --to jpg`, `filee watch`, вывод JSON и коды завершения.

- Что сделать: команда `mangosteen convert` на том же `Converter`; установка ссылки в `/usr/local/bin` из
  настроек.
- Стоимость: 3–4 дня. Размер: +0,2–0,5 МБ.
- `Converter` и конвертеры уже отделены от интерфейса и покрыты тестами, поэтому дёшево.

### 9. Горячая клавиша для колеса

У Filee: круг открывается клавишей, кнопкой мыши или жестом удержания.

- Что сделать: клавиша для служб Finder (поле `NSKeyEquivalent`, разрешений не требует) и общая горячая клавиша
  для выбранных в Finder файлов; стрелки, Return и Esc на самом колесе.
- Стоимость: 2–3 дня. Размер: 0.
- Закрывает пункты доступности из отчёта проверки (колесо без клавиатуры, нет Esc).

| PDF: диапазон страниц текстом («1-3, 8, 12-») в «Разделить» | 1 день | 0 |

### 11. Языки интерфейса

У Filee 22 языка, у нас 3. Строк 477; сам перевод недорог, но каждый язык нужно проверять снимками (подписи на
колесе ужимаются под длину слова).

- Стоимость: 1–1,5 дня на язык с проверкой снимками. Размер: +30–40 КБ на язык.
- Кандидаты: немецкий, французский, португальский, китайский, японский. Перевод нужен от носителя или хотя бы
  вычитка — машинный перевод интерфейса заметен.

### 12. Электронные книги

- EPUB → TXT, HTML, PDF своими силами (EPUB — это ZIP с HTML; читатель ZIP и импорт HTML у нас есть):
  4–5 дней, размер 0. Сложная вёрстка и картинки перенесутся грубо.
- MOBI, AZW3 и запись книг требуют calibre: около +400 МБ **[по документации]** — не рекомендую.

### 13. Увеличение картинок и перевод локальным ИИ

- Увеличение 2–4× моделью Core ML: 6–8 дней, +20–70 МБ на модель (оценка по размерам открытых моделей
  Real-ESRGAN; конкретную модель и её лицензию надо выбирать отдельно).
- Перевод документов и субтитров через системный перевод macOS 15+: 5–7 дней, размер 0, но функция будет
  недоступна на macOS 14 **[по документации]**.

### 14. Офисные форматы — не рекомендую сейчас

PPTX → PDF, XLSX → PDF, точная вёрстка DOCX → PDF, HWP, CAD, 3D, шрифты, геоданные — главное преимущество Filee.
Они написали собственные движки и ведут их в каждом выпуске (в 2.4.0 — больше десятка исправлений Word и HWPX).

- Через LibreOffice: +300–700 МБ внутри приложения или скачивание по запросу (нужны сеть и менеджер движков,
  10–15 дней).
- Свой движок: месяцы работы.
- Дешёвый компромисс: если у пользователя установлены Pages, Numbers и Keynote, просить их экспортировать в PDF
  (4–6 дней, размер 0, но нужно разрешение на управление этими приложениями).

## Что потребует вашего решения

1. **Сеть.** Автообновление в фоне, скачивание ссылок из браузера и модели по запросу нарушают нынешнее правило
   «в сеть только по кнопке обновлений». Каждое можно сделать выключенным по умолчанию.
2. **Размер против возможностей.** Всё до пункта 12 включительно почти не увеличивает приложение. Пункты 13–14 и
   Whisper внутри увеличивают его в разы и отнимают наше главное отличие от Filee.
3. **Нотаризация.** Ни Filee, ни мы её не делаем; с ней установка без предупреждений стала бы преимуществом.
4. **Windows и Linux.** Оценки только для macOS. Пункты 1 и 4 там делаются другими средствами (нет ImageIO,
   системного `tar` с теми же возможностями и распознавания речи macOS).
