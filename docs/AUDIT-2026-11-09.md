## 1. Ошибки, которые стоит исправить

### 1.1. «Склеить»: вертикальные видео с телефона попадают в горизонтальный кадр — [проверено]

`MediaEffects.join` берёт размер холста из `ffprobe` (`MediaEffects.swift:64-71`), а `MediaConverter.probe`
(`MediaConverter.swift:60-77`) не учитывает поворот. Для ролика с поворотом 90° ffprobe отдаёт 640×360, а ffmpeg
декодирует кадры 360×640. Вертикальный ролик первым в списке даёт горизонтальный холст с полями по бокам.
В `cropVideo` это уже учтено (размер берётся с декодированного кадра).

Исправление: читать `side_data.rotation` в `probe` и менять стороны местами, либо брать размер через
`VideoRedactor.frameSize`.

### 1.2. На Intel-Mac встроенные утилиты не запустятся — [проверено]

Приложение собрано универсальным (x86_64 + arm64), а `ffmpeg`, `cwebp` и библиотеки в `Contents/Resources/Tools` —
только arm64 (берутся из `/opt/homebrew`). `ExternalTool.locate` находит их как исполняемые, запуск падает.
В README указано только «macOS 14+».

Исправление: собирать приложение только под arm64 и написать это в README, либо класть универсальные утилиты.

### 1.3. CSV с точкой с запятой читается как один столбец — [по коду]

`TableConverter.separator` (`TableConverter.swift:32-34`) знает только запятую и табуляцию. Excel в русской и
испанской локали сохраняет CSV через `;`, такой файл превратится в XLSX из одного столбца.

Исправление: определять разделитель по первой строке (`;`, `,`, табуляция вне кавычек). Отдельно стоит решить,
писать ли BOM в CSV: без него Excel показывает кириллицу кракозябрами.

### 1.4. Текст не в UTF-8 всегда читается как Windows-1251 — [по коду]

`DocumentConverter.readText` (`DocumentConverter.swift:43-47`): после UTF-8 идёт cp1251, который подходит почти к
любым байтам. Испанский файл в Latin-1 или Windows-1252 получит кириллицу вместо `ñ`, `á`. Затрагивает TXT, MD,
CSV, TSV, SRT, VTT.

Исправление: `NSString.stringEncoding(for:encodingOptions:convertedString:usedLossyConversion:)` с набором
кандидатов (cp1251, cp1252, UTF-16), либо выбор по языку системы.

### 1.5. Анимированный GIF после «Сжать», «Обрезать», «Редактор» становится одним кадром — [по коду]

`ImageConverter.load` отдаёт только главный кадр, а инструменты для изображений предлагаются и для GIF
(`WheelItemProvider.swift:96-121`, `isCompressible`). Результат «(сжатый).webp» без анимации выходит молча.

Исправление: для многокадровых файлов либо не предлагать эти инструменты, либо предупреждать, либо сжимать GIF
через `gif2webp` или ffmpeg.

### 1.6. Обычный `.gz` считается архивом TAR.GZ — [проверено]

`FileFormat.extensionAliases` (`FileFormat.swift:164`) отображает `gz` в `.tgz`. Для `note.txt.gz` колесо предложит
«Распаковать» и ZIP/TAR, а `tar -xf` завершится с кодом 1 и сообщением «Missing type keyword in mtree
specification».

Исправление: убрать псевдоним `gz` или распаковывать одиночный gzip через `gunzip -k`.

### 1.7. Две кнопки на клавише Return в одном окне — [проверено снимком]

В «Разделении» и «Кадрах» кнопки «Разрез по курсору» и «Добавить кадр» получают
`.keyboardShortcut(.return, modifiers: [])` (`MediaToolViews.swift:128`, `:228`; то же в «Запикать»,
`AudioToolViews.swift:370`), а главная кнопка в `ToolFooter` — `.defaultAction` (`ToolWindow.swift:129`). На снимке
обе залиты как кнопки по умолчанию. Какая сработает по Return, зависит от порядка в иерархии; пользователь ждёт
«Разделить на 3».

Исправление: дать разрезу другую клавишу (например, `S` или `M`) и оставить Return главной кнопке.

### 1.8. Выход из приложения во время работы оставляет процессы и скрытые файлы — [по коду]

Нет `applicationShouldTerminate`: запущенные `ffmpeg` продолжают работать после выхода, а временные
`.mangosteen-<UUID>.*` (`OutputNaming.swift:40`) и папка подготовки архива (`ArchiveConverter.swift:55`) остаются
рядом с оригиналами и не убираются никогда.

Исправление: при выходе отменять все `CancellationToken` и ждать завершения; при запуске удалять старые
`.mangosteen-*` в папках из истории, либо писать во временный каталог на том же томе.

### 1.9. Предупреждение ffprobe ломает чтение файла — [по коду]

`MediaConverter.probe` вызывает `ExternalTool.run`, который сливает stderr в stdout (`ExternalTool.swift:131-147`).
Любая строка ошибки от ffprobe для слегка повреждённого файла попадёт в JSON, и файл будет объявлен нечитаемым.
Там же вывод ошибки не обрезается (в `runStreaming` обрезается до 800 символов), так что окно ошибки может
получить несколько экранов текста.

Исправление: читать JSON через `runData` (stdout отдельно), в `run` обрезать текст ошибки.

## 2. Интерфейс

1. **Окно показывает «и ещё N», а работает с одним файлом.** «Обрезать» и «Разделить» медиа, «Кадры», «Каналы»,
   «Запикать», «Скрыть» на видео, «Пометки», «Разделить PDF» берут первый файл (`MediaToolViews.swift:3-5`), но
   заголовок окна строится по всем (`ToolWindow.swift:37-40`). Остальные файлы молча пропадают. Стоит либо
   передавать в заголовок один файл, либо писать «используется первый из N».
2. **Нет сигнала о завершении, если выключены звук и «Показывать в Finder».** Панель прогресса не появляется для
   задач короче 0,5 с и просто исчезает для длинных (`ProgressHUD.swift`). Нужна короткая отметка «Готово» с
   кнопкой «Показать».
3. **Задачи `runBatch` показывают «0 из 1 · 0%» до конца** и не останавливаются (`ConversionService.swift:75-89`):
   коллаж, объединение и создание PDF, архив, кадры, деление PDF. То же внутри одного файла у PDF → картинки и
   сжатия PDF. Нужен неопределённый индикатор или прогресс по страницам.
4. **Кнопка «Остановить» отменяет все задачи сразу** (`ProgressHUD.swift:127-133`), даже запущенные из разных окон.
5. **Колесо, открытое из меню или из служб Finder, не закрывается по Esc** и не закрывается кликом по собственному
   окну Mangosteen: используется только глобальный монитор (`WheelController.swift:81-87`).
6. **Ошибка показывается модальным окном с захватом фокуса** (`ConversionService.swift:163-168`). Для фоновой
   утилиты это прерывает работу в другом приложении; несколько задач дают несколько окон подряд.
7. **«Сжатие» для одних PDF** показывает «Формат» и «Сохранять метаданные», которые на PDF не действуют, и не
   даёт оценки размера (`CompressView.swift:150-154`).
8. **«Проверить обновления»**: нет признака, что запрос идёт; повторные нажатия дают несколько окон; лимит GitHub
   (HTTP 403) показывается как «проверьте подключение» (`UpdateChecker.swift:26-63`).
9. **Числа с «px»** в «Коллаже» и «Сжатии» форматируются по региону («3 000 px» в английском интерфейсе на
   снимке), в «Обрезке» — без разделителя (`CollageView.swift:69`, `CompressView.swift:135`).
10. **«Как пользоваться»**: ролик всегда с английскими подписями; карточки трёх колёс разной высоты (снимок es).
11. **Float**: двойной клик по «Перетащить все» открывает все файлы (`FloatShelf.swift:341-346`).
12. **«Удалить результат»** в истории: ошибка перемещения в Корзину не показывается (`MenuBarController.swift:180-183`).

По снимкам подписи на колёсах и в окнах нигде не обрезаны (ru, en, es).

## 4. Расход ресурсов

1. **Слежение за перетаскиванием** (`DragMonitor.swift:61-69`). Глобальный обработчик срабатывает на каждое
   событие движения мыши с нажатой кнопкой во всей системе и каждый раз обращается к буферу перетаскивания. Если
   тащат не файл (текст, картинку из браузера), `readObjects` вызывается на каждое событие до конца
   перетаскивания. Достаточно проверять раз за жест и повторять несколько раз с паузой 50–100 мс.
   Таймер 120 Гц во время перетаскивания (`:100`) можно снизить до 60.
2. **Параллельность без ограничения по памяти** (`ConversionService.swift:47`). Для изображений, PDF и OCR
   работает столько задач, сколько ядер; каждая держит раскодированную картинку, а OCR рисует страницу в 300 dpi
   без ограничения размера (`PDFConverter.swift:43-50`). На 60 фото по 48 Мп или PDF большого формата это
   гигабайты. Стоит ограничить тяжёлые операции 3–4 потоками и размер страницы в пикселях.
3. **PDF из многих фото** держит все раскодированные картинки до записи (`PDFTools.swift:29-44`): у повёрнутых
   фото с телефона это около 48 МБ на снимок.
4. **Коллаж** грузит каждое фото в полную ширину результата (`CollageComposer.swift:188-196`), хотя ячейка
   меньше; до 36 МБ на фото при ширине 3000.
5. **Предпросмотр не отменяется.** `Task.detached` не получает отмену внешней задачи: при движении ползунка
   старые расчёты доходят до конца параллельно с новыми. Тяжелее всего «Сжатие» (`CompressView.swift:175-185`):
   режим «Размер файла» делает до полусотни кодирований, а каждое WebP — это PNG на диск и запуск `cwebp`
   (`ImageConverter.swift:93-102`). То же в «Редакторе» (`PhotoEditView.swift:218-231`) и «Коллаже»
   (`CollageView.swift:223-238`).
6. **Миниатюры PDF строятся в главном потоке для всех страниц сразу** (`PDFSplitView.swift:166-170`,
   `PDFOrganizeView.swift:144-150`); на документе в сотни страниц окно будет подтормаживать. Нужна ленивая
   загрузка по видимым ячейкам в фоне.
7. **Сжатие PDF «Размер файла»** — до пяти полных проходов без отмены и прогресса (`ImageCompression.swift:174-213`).
8. **Колесо** пересчитывает раскладку подписей всех долек при каждой смене подсветки (`WheelView.swift:165-238`);
   результат можно запомнить в `configure`.
9. **Мелочи**: Float перестраивает все строки при каждом наведении (`FloatShelf.swift:208-210`); для MP3 каждый
   `probe` заново считает пакеты всего файла, а инструменты вызывают `probe` по 2–3 раза; «В архив» на томах без
   APFS копирует файлы целиком (`ArchiveConverter.swift:58-62`).

## 5. Распространение и безопасность

1. **Подпись ad hoc, без нотаризации и hardened runtime** (`project.yml:35-36`, отмечено в `SECURITY.md`): на
   чужом Mac Gatekeeper блокирует запуск. Для публичных релизов нужны Developer ID и нотаризация.
2. **FFmpeg под GPL v3** лежит внутри релиза (собран с `--enable-gpl`, x264, x265). README это упоминает; в самом
   архиве релиза и в окне «О Mangosteen» текста лицензии и ссылки на исходники нет. Условия GPL при
   распространении бинарников стоит сверить отдельно — это не юридическое заключение.
3. **Запасной поиск утилит** в `/opt/homebrew/bin` и `/usr/local/bin` (`ExternalTool.swift:33-42`) срабатывает
   только когда встроенных нет; для релизной сборки его можно отключить.
4. Команды запускаются без оболочки, архивы распаковывают `ditto` и `tar` с защитой по умолчанию, ZIP-читатель
   ограничивает размер — замечаний нет.
