# Mangosteen — контекст для продолжения работы

Снимок состояния на 2026-10-27. Помечено: **[факт]** — проверено по коду, git или тестам; **[предп.]** — предположение.
Подробный исходный план функций — `docs/PLAN.md`; пользовательское описание — `README.md` / `README.ru.md`.

## 1. Цель проекта и текущая задача

- Mangosteen — офлайн-утилита в строке меню macOS «в ноль кликов»: начните тащить файл, коротко нажмите модификатор,
  у курсора откроется колесо (⇧ Конвертация, ⌘ Инструменты, ⌃ Действия), бросьте файл на дольку. Результат пишется
  рядом с оригиналом, оригинал не меняется. Без телеметрии, лимитов и сторонних сервисов. [факт]
- Репозиторий: `SpaceCadet0/Mangosteen` (этот каталог). Windows-версия — отдельный репозиторий
  `SpaceCadet0/Mangosteen-Windows` в `~/Work/Mangosteen Windows` (своя сессия Claude). [факт]
- Текущей незавершённой задачи нет: последние запросы (сжатие PDF, «Проверить обновления») выполнены и запушены. [факт]
- Пользователь пишет по-русски, проверяет каждый шаг сам и обычно просит после изменения на macOS передать то же
  в Windows-сессию. [факт]

## 2. Стек и архитектура

- Swift 5, AppKit + SwiftUI, macOS 14+, XcodeGen (`project.yml` → `Mangosteen.xcodeproj`, не править руками). [факт]
- Агент без Dock (`LSUIElement`), не песочница. Debug-сборка — отдельный bundle id `dev.mangosteen.app.debug`. [факт]
- Встроенные утилиты: ffmpeg, ffprobe, cwebp, gif2webp (кладутся в `Contents/Resources/Tools` скриптом
  `scripts/bundle_tools.py`). [факт]
- Каталоги `Mangosteen/`:
  - `App/` — AppDelegate (в т. ч. DEBUG-режим снимков), MenuBarController + MenuRowView (меню строки состояния),
    ConversionService (очередь задач, HUD, отмена), OperationHistory, FinderServices, UpdateChecker, Brand.
  - `Wheel/` — WheelController, WheelView (рисование и раскладка подписей), WheelItemProvider (какие дольки для
    каких файлов); перетаскивание отслеживает `Core/DragMonitor`.
  - `Core/` — FileFormat, FormatCatalog (цели конвертации), OutputNaming, ModifierChoice, DragMonitor.
  - `Conversion/` — конвертеры и обработка (Image/Media/Document/PDF/Archive/XLSX, ImageCompression, ImageCropper,
    FrameComposer, TextRecognizer, BackgroundRemover, Redactor и др.).
  - `Tools/` — окна инструментов (SwiftUI) и ToolWindow/ToolFooter/`toolForm()`.
  - `Support/` — ExternalTool, ZipArchive, CancellationToken, AppVersion.
- Тестовая цель `MangosteenTests` включает только `Core`, `Conversion`, `Support` и `App/OperationHistory.swift`:
  код из `App/`, `Wheel/`, `Tools/` в тестах недоступен. [факт]
- Демо-анимации — Remotion-проект `promo/` (`promo/README.md`). [факт]

## 4. Изменения последнего этапа (после релиза v0.10.1, 16 коммитов, все запушены)

- Колесо: при смешанном выборе только общие инструменты («Сжать», «Метаданные», «Текст», «В архив»); у каждой
  дольки обязательно есть значок; подписи ужимаются, а не вылезают за дольку; EN «Remove bg». [факт]
- Убраны: BMP с колеса конвертации (BMP остаётся форматом чтения и сохранения правок); долька «PDF из фото» —
  вместо неё конвертация нескольких фото в PDF собирает один `Images.pdf`. [факт]
- «Обрезать» → вкладка «Размер» (пиксели, %, длинная сторона, одно правило для всех файлов); «Сжать» → «Своё…»
  для длинной стороны. [факт]
- «Фон»: скругление до 100% и переключатель «Круг». Формы настроек выровнены по верху превью (`toolForm()`). [факт]
- Меню строки состояния подсвечивается фирменным цветом. [факт]
- OCR: прогресс, «Стоп», лимит 60 с на картинку или страницу. [факт]
- Сжатие PDF: страницы без текстового слоя перерисовываются в JPEG (на тестовом 4-страничном скане
  47,7 МБ → 1,6 МБ «Сбалансированно»). [факт]
- «Проверить обновления…» в меню и в окне «О Mangosteen» (GitHub releases/latest, только открывает страницу
  релиза). [факт]
- README и анимации обновлены под новые колёса (без BMP и «PDF из фото»). [факт]

## 5. Ключевые решения и причины

- Фирменный цвет #671E38 (`Brand.swift`); в тёмной теме для текста — #CC6890. [факт]
- Меню рисуется вручную (`MenuRowView`): системное NSMenu подсвечивает пункты всегда голубым и игнорирует
  акцент приложения, даже когда `AccentColor` задан в ассетах. [факт]
- Сканы в PDF перерисовываются через Quartz с JPEG-картинкой: опции PDFKit `saveImagesAsJPEG` /
  `optimizeImagesForScreen` несжатые картинки не трогали. Страницы с текстом не растрируются. [факт]
- OCR выполняется в отдельном потоке и ждёт с дедлайном: первая загрузка моделей Vision занимает ~14 с, и раньше
  это выглядело как зависание. [факт]
- Сжатие и конвертация никогда не перезаписывают оригинал; если результат не меньше оригинала, «Сжать» его не
  сохраняет. [факт]
- Подписи на колесе: шрифт от 11,5 до 8 pt, перенос в 2 строки, сдвиг по радиусу; на колёсах из 10+ долек значок
  14 pt. Вариант без значка пользователь запретил. [факт]
- Сравнение версий вынесено в `Support/AppVersion`, чтобы его можно было тестировать. [факт]

## 6. Ограничения и требования, которые нельзя нарушать

- Оригинал не изменяется никогда; результат пишется рядом (`OutputNaming.writeAtomically`, номер при занятом
  имени). [факт]
- Работать только локально: из сети ходит лишь «Проверить обновления» и только по нажатию. [факт]
- У каждой дольки есть значок, подпись внутри дольки; проверять снимками на ru/en/es. [факт]
- Каждое изменённое окно перед сдачей снимается (DEBUG `--snapshot`) и проверяется визуально; в меню снимки делать
  через `cacheDisplay`, а не через снимок экрана. [факт]
- Новые строки: русский ключ в коде → перевод в `scripts/translations.json` →
  `python3 scripts/check_translations.py --write` (после сборки), итог должен быть «0 missing». [факт]
- После добавления файла запускать `xcodegen generate`. [факт]
- Хук GateGuard требует перед первой правкой файла или командой перечислить факты (кто использует файл, что
  затронуто, данные, цитата запроса). `rm -rf` с переменными — только в форме `${VAR:?}`. [факт]
- Личные файлы пользователя (документы) не открывать визуально без необходимости, копии удалять после проверки. [факт]

## 7. Известные ошибки, незавершённое, техдолг

- Новые функции не выпущены: последний релиз v0.10.1, а `MARKETING_VERSION` всё ещё 0.10.1. Для релиза нужно поднять
  версию. [факт]
- Не проверено вживую:
  - диалог «Проверить обновления» (проверено только, что API отдаёт `tag_name` и `html_url`);
  - кнопка «Стоп» в OCR во время работы;
  - холодный медленный запуск OCR в самом приложении;
  - качество сжатого скан-PDF глазами (проверена только структура). [факт]
- `ConversionService` и `WheelItemProvider` не покрыты тестами: они не входят в тестовую цель. [факт]
- Сжатие PDF, исправлено (не закоммичено): страницы с текстом и картинками без потерь (экспорт Google Docs: 11 стр.,
  18 скриншотов Flate, 5,5 МБ) раньше не сжимались: PDFKit картинки не трогает, результат был больше оригинала.
  Теперь `ImageCompression.filteredCopy` пропускает документ через QuartzFilter (JPEG, dpi и качество шага), текст и
  ссылки остаются; сканы по-прежнему перерисовываются в JPEG. На том файле 5,5 → 1,8 МБ («Сбалансированно»),
  1,05 МБ («Мелкий»). Тест `testImagesOnTextPagesAreReencodedAndTextStays`; 128 тестов проходят. Качество страниц с
  картинками глазами не проверено (страница без картинок чёткая). [факт]
- Растрирование применяется ко всем страницам без текста: векторная страница без текста (схема) тоже станет JPEG.
  [факт по коду]
- В README нет пунктов про распознавание текста, удаление фона и «Проверить обновления». [факт]
- Демо-анимации актуальны: в `promo/src/Demo.tsx` нет BMP и «PDF из фото», сцена «Инструменты» показывает видео. [факт]
- Сессию «Linux», на которую ссылался пользователь, найти не удалось; кнопка обновлений сделана по стандартной
  схеме. [факт]
- Windows (отдельный репозиторий): релиз 1.3.3 с «Проверить обновления». У пользователя Windows-версии была ошибка
  `ffprobe.exe exited with code -1073741515` (0xC0000135, не найдена DLL); исправление этой ошибки в Windows-сессию
  не передавалось. [факт: передача; предп.: причина — недостающие DLL ffmpeg или VC++ Redistributable]

### Полезные команды

```bash
xcodegen generate
xcodebuild test -scheme Mangosteen -destination 'platform=macOS' -derivedDataPath build.noindex/test
python3 scripts/check_translations.py --write
scripts/release.sh --install
```

Снимок окна (DEBUG): `build.noindex/test/Build/Products/Debug/Mangosteen.app/Contents/MacOS/Mangosteen
--snapshot <tool.id|wheel.convert|wheel.tools|wheel.actions|menu|about|welcome> <out.png> <files…>`. Переменные
окружения: `MANGOSTEEN_APPEARANCE=light|dark`, `MANGOSTEEN_DEMO=1`, `MANGOSTEEN_SNAPSHOT_DELAY`,
`MANGOSTEEN_MENU_HIGHLIGHT=<заголовок>`, плюс `-AppleLanguages "(en)"`. Окно снимается командой
`screencapture -l <id из лога>`.
